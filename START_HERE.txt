🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

  Problem: Backend won't start
    → Check port 8000: lsof -i :8000
    → Kill process: kill -9 <PID>

  Problem: Frontend won't start
    → Check port 5173: lsof -i :5173
    → Delete node_modules: rm -rf node_modules
    → Reinstall: npm install

  Problem: No data in dashboard
    → Check if systems are running
    → Check folders: ls -la /home/test/IDS/systems/ML/alerts/
    → Check backend: curl http://localhost:8000/api/status

  Problem: CORS errors in console
    → Restart backend
    → Check .env.local has VITE_API_BASE_URL=http://localhost:8000
