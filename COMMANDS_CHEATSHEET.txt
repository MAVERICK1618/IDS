───────────────────────────────────────────────────────────────────────────────
TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────

Port Already in Use:
  lsof -i :PORT
  kill -9 PID

Module Not Found:
  # Frontend
  cd /home/test/IDS/frontend && rm -rf node_modules && npm install

  # Backend
  cd /home/test/IDS/backend && source venv/bin/activate && pip install flask

API Calls Failing:
  1. Check backend running: curl http://localhost:8000/api/status
  2. Check VITE_API_BASE_URL in .env.local
  3. Check DevTools Console (F12) for errors

No Data in Frontend:
  1. Check if systems are running (ML/alerts folder should have JSON files)
  2. Check backend logs for read errors
  3. Restart backend and frontend
